# 设计系统（aimodel）

> `ui-designer` 产出。`frontend-implementer` 严格遵循本规范，禁止内联硬编码样式。
> 定位：**本地工具型 AI 产品仪表盘**——信息密度中等、信任感优先（隐私可视化）、打开即用。

## 1. 设计原则

1. **信任优先**：隐私徽标常驻（"检测均在本机完成"），让用户敢用。
2. **状态完备**：每个数据块必有 加载/正常/空/错误 四态（对应 roles.md 3.6 要求）。
3. **用户语言**：界面文案不用开发者术语（不出现 API/JSON/SDK），"报告"不用"响应"。
4. **打开即用**：首屏无引导墙，直接看到硬件报告；刷新一键可达。

## 2. 色板（暗色为主，跟随系统可选浅色）

| Token | 暗色值 | 用途 |
|-------|--------|------|
| `--bg` | `#0E1116` | 页面背景 |
| `--surface` | `#161B22` | 卡片面 |
| `--border` | `#262C36` | 描边/分隔 |
| `--text` | `#E6EDF3` | 主文字 |
| `--text-muted` | `#8B949E` | 次要文字/单位 |
| `--accent` | `#2F81F7` | 主色（按钮/高亮/进度条） |
| `--success` | `#3FB950` | 正常/空闲状态 |
| `--warn` | `#D29922` | 警示（磁盘不足等） |
| `--danger` | `#F85149` | 错误态/离线 |
| 浅色模式 | 语义对应翻转（bg→#FFFFFF, surface→#F6F8FA, text→#1F2328） | `prefers-color-scheme` |

## 3. 字体与排版

- 正文字体栈：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`（系统字体，零下载，离线可用）。
- 数字展示：`font-variant-numeric: tabular-nums`（对齐）；JSON/原始值：`ui-monospace, Consolas, monospace`。
- 字号：标题 18px / 卡片标题 14px / 正文 14px / 辅助 12px；单位用 `--text-muted` 小一号显示。

## 4. 间距、圆角、投影

- 间距基准 4px：`4 / 8 / 12 / 16 / 24 / 32`。
- 圆角：卡片 12px、按钮/徽标 8px、进度条全圆。
- 卡片：`--surface` 底 + 1px `--border` 描边；不用重投影（本地工具轻量感）。

## 5. 核心组件

| 组件 | 规格 | 状态 |
|------|------|------|
| 顶栏 | 产品名 + 隐私徽标（盾牌🛡"数据仅在本机"）+ 刷新按钮 | 刷新中：按钮转圈 + `aria-live` 播报 |
| 硬件卡片 | 标题（图标+名称）+ 主值 + 明细行 + 可选进度条 | 见 §6 四态 |
| 进度条 | 高 8px，`--accent`；使用率 >85% 转 `--warn`，>95% 转 `--danger` | — |
| 状态徽标 | 打印机/磁盘状态点：空闲绿 / 打印中蓝 / 离线灰 / 错误红 | — |
| 骨架屏 | 卡片内灰块脉冲动画，禁止整页 spinner | — |

## 6. 四态规范（每个数据块必须实现）

| 态 | 触发 | 视觉 | 文案 |
|----|------|------|------|
| 加载 | 请求未返回 | 骨架屏 | —（顶栏播报"正在检测…"） |
| 正常 | 有数据 | 卡片内容 | 数据本身 |
| 空 | 字段空数组/0 且非错误 | 图标 + 居中文案 | 如"未检测到打印机" |
| 错误 | 请求失败/超时 | 卡片错误态 + 重试按钮 | "检测失败，点击重试"（不暴露技术细节） |

## 7. 可访问性

- 文字对比度 ≥ 4.5:1（所选色板满足）。
- 键盘可达：刷新/重试按钮可 Tab 聚焦，焦点环 `2px --accent`。
- 语义化结构：`<header>/<main>/<section aria-labelledby>`；进度条用 `role="progressbar"` + `aria-valuenow`。
- 不用颜色单独传达状态（配文字/图标）。
