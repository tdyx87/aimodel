# 存档查看器

在本地查看游戏存档，**只读取，从不修改**。

存档文件是游戏自动保存的进度。游戏本身通常不告诉你「我到底解锁了哪些成就」「我的存档里还剩什么」，坏掉的存档更是让你两眼一黑。这个小工具帮你把这些内容直接摊开看。

---

## 它能帮你做什么

- **看进度**：每个存档位存到第几章、攒了多少金币、玩了多久、拿到了哪些道具和解锁了哪些成就。
- **导出留底**：把某个存档位导成 JSON 文件或一段可以直接粘贴的文字报告。
- **诊断问题**：存档读不出来、游戏读不进去时，告诉你**是哪里出了问题**、**为什么**、以及**你能做什么**。

## 它不会做什么

这几条是产品承诺，不是宣传语：

- **绝不修改你的存档文件**。工具以只读方式打开文件，全程没有写入通道。
- **数据不会离开你的电脑**。没有任何联网上传，也没有统计或崩溃上报。
- **不会替你修存档**。它只看不改。

## 安装

| 系统 | 步骤 |
|------|------|
| **Windows** | 下载 `.msi` 或 `.zip`，双击安装；压缩包版本解压后直接运行其中的 `save_inspector_ui.exe` |
| **macOS** | 把应用拖进「应用程序」，或从「下载」里双击打开 |
| **Linux** | 用软件中心安装 `.deb`，或给压缩包里的 `save_inspector_ui` 加上可执行权限后运行 |

首次启动时，你的系统可能提示「来自身份不明的开发者」。这是因为这个版本还没有做代码签名。选择「仍要打开」即可，功能不受影响。

## 上手（3 步出结果）

1. **启动**：双击 `save_inspector_ui`，浏览器会自动打开工具页面。
2. **选文件**：把存档文件**拖进页面中间的方框**，或点击方框后从文件列表里选一个。
   - 存档一般在游戏的安装目录或用户数据目录里。常见位置：
     - Windows：`%USERPROFILE%\Documents\My Games\<游戏名>\`
     - macOS：`~/Library/Application Support/<游戏名>/`
     - Linux：`~/.local/share/<游戏名>/`
3. **看结果**：中间会列出这个存档里的所有存档位。点任意一个查看详情，或者直接用「导出」把内容存下来。

> 找不到存档文件？在游戏主菜单里找「存档管理」或「同步存档」，通常会显示存档所在的位置。

## 界面说明

| 你看到的 | 意思 |
|---------|------|
| **打开存档**（右上角） | 换一个存档文件 |
| **换一个存档** | 同上，回到选文件那一步 |
| **正常**（绿色标签） | 这个存档位的数据完整 |
| **存在异常**（红色标签） | 这个存档位有问题，但**通常还能看**——点进去会尽量显示能读到的内容 |
| **空槽位** | 这个存档位还没用过 |
| **换个存档后的提示条** | 说明哪里坏了、为什么、以及建议怎么做 |
| **导出 JSON / 导出可读报告** | 把当前存档位存成文件。JSON 适合自己分析；可读报告适合直接贴进客服工单 |

顶部的「只读取，不修改」和底部的「所有解析都在你的电脑上完成」不是装饰——这是工具的实际行为。
