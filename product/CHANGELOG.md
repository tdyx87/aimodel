# 版本记录

本文描述**用户视角**的版本变化。开发者相关的构建与内部改动不在此记录。

本项目遵循[语义化版本](https://semver.org/lang/zh-CN/)：主版本号表示不兼容的改变，次版本号表示新增功能，修订号表示问题修复。

---

## 0.1.0 — 2026-10-13

首个可用版本。

### 新增

- **查看存档内容**：列出存档里的所有存档位，每个显示关卡进度、金币、游玩时长与最近游玩时间。
- **查看存档位详情**：道具清单与已解锁成就一览。
- **导出**：把存档位内容导出为 JSON 文件，或导出为可直接粘贴进客服工单的中文文本报告。
- **损坏诊断**：存档读不出来时，说明**哪里坏了**、**为什么坏**、**你能做什么**，而不是丢一个错误代码给你。
- **部分损坏仍可读**：某个存档位有问题时，其余存档位和该存档位中能读出的内容照常显示。
- **兼容旧版本存档**：早期格式的存档会自动按新版规则读取，并标注「已升级读取」。

### 已知限制

- 加密的存档无法读取，需要游戏本体解开。
- 使用了压缩的存档只能识别、不能解压，部分内容可能显示不全。
- 只支持本工具定义的一种存档格式；其它游戏的存档需要等待适配。
- 道具名称只覆盖内置的少数几种，其余显示为编号。
- 本版本还没有做代码签名，首次运行系统可能提示「来自身份不明的开发者」。

### 隐私

本版本**完全在本地运行**：没有联网上传、没有统计、没有崩溃上报；且工具不具备修改存档的能力。
