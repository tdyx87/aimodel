## 对话/推荐入口（chat system）

> 需求：`product/docs/prd/PRD-chat-system.md`；契约：`product/docs/design/chat-system-contract.md`。
> 形态：在硬件报告页增量加入「问问我的电脑」模块——输入一句自然语言问题，
> 返回**本机配置摘要 + 推荐分类（可以运行/需要检查/不建议）+ 可执行下一步 + 不确定性声明**。

| 优先级 | 项 | 说明 |
|--------|-----|------|
| **Must** | 界面入口（不改动现有卡片顺序） | `[已交付]` |
| **Must** | 本地规则式建议（不调用外部模型） | `[已交付]` |
| **Must** | 回答含用户实际配置摘要 | `[已交付]` |
| **Must** | 回答含分类与可执行下一步 | `[已交付]` |
| **Must** | 隐私：仅 127.0.0.1、零出站、输入不落盘 | `[已交付]` |
| **Should** | 多轮对话记忆 | 划入 v0.2+（PRD §3.2 显式排除） |
| **Won't** | 大模型驱动的问答/推理 | 划入 v0.2（依赖 Q1） |

**门禁**：G1（PRD/契约/界面稿审计）、G2（实现 + `reviewer` ✅）、G3（`ctest` 38/38 + `security-reviewer` 无 Critical/High）均已放行，见 `product/docs/audit/2026-10-12-*.md`。

## v0.2 硬件自适应选型

兑现 `agents.md` 第 1 节与 README 的核心承诺。**本期只占位，需先出独立 PRD。**

方向（依据 `agents.md` 第 1 节表述）：
- 依据检测结果自动决定用显卡还是 CPU 运行；
- 依据显存/内存自动匹配模型规格；
- 全程不要求用户手动配置。

**依赖**：需先裁决 Q1（是否兑现），并新增推理引擎与模型管理模块 —— 属架构级扩展，须 `architect` 先出契约。
