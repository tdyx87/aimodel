# 常见问题

## 关于安全性

**Q：这个工具会不会改坏我的存档？**

不会。工具以只读方式打开文件，程序里**没有任何写入存档的通道**——不是「写了但加保护」，是根本没有这个功能。你可以放心反复打开同一个存档。

**Q：它会上传我的存档吗？**

不会。所有解析都在你的电脑上完成，工具**完全没有联网行为**，也没有统计或崩溃上报。你可以断网使用，功能不受影响。

**Q：导出的文件安全吗？**

导出的内容与界面上看到的完全一致，且**不包含你电脑上的任何路径信息**。如果你要把导出的报告发给客服，文件名是 `save-slot-1.json` 这类形式，不泄露你的用户名或目录结构。

## 关于存档位置

**Q：我不知道存档文件在哪。**

打开游戏主菜单，找「存档管理」「同步存档」或「云存档」，通常会直接显示路径或提供「打开存档文件夹」的按钮。

常见位置：

| 系统 | 路径 |
|------|------|
| Windows | `%USERPROFILE%\Documents\My Games\<游戏名>\` |
| macOS | `~/Library/Application Support/<游戏名>/` |
| Linux | `~/.local/share/<游戏名>/` |

Steam 版游戏还可能在 `Steam/steamapps/common/<游戏名>/` 下。

**Q：我能看到存档文件的名字，怎么知道哪个是我要的？**

看**修改时间**——最新那个通常是你最近在玩的存档位。游戏界面的存档位编号一般与文件名中的数字对应。

## 关于读取失败

**Q：提示「这不是存档文件」。**

选错了文件。常见误选：存档的备份压缩包、游戏截图、或者另一个游戏的存档。确认文件名和修改时间。

**Q：提示「存档不完整」。**

文件在保存过程中被中断了——比如游戏崩溃或电脑断电时正好在保存。**如果游戏本身还能读到这个存档，请先用游戏本体打开一次并重新存档**，工具只能读取无法修复。

**Q：提示「存档来自更新版本的游戏」。**

你的游戏比这个工具新。先在游戏里打开一下存档（确认能正常读取），或者等工具更新以支持新格式。

**Q：提示「该存档已加密」。**

这种存档必须由游戏本体才能解开。工具没有密钥，也不会尝试破解。请用游戏本体打开一次并重新存档。

**Q：某个存档位显示「存在异常」，但点进去还能看到内容。**

这是正常的。存档里这部分数据与游戏写入时记录的不一致——可能被其他存档编辑工具改过，也可能在保存时断电。工具会尽量显示还能读到的内容，其余部分标注出来。

**建议**：先把这个存档文件复制一份备份，再用游戏本体打开一次并重新存档。

**Q：所有存档位都读不出来。**

先确认选对了文件（见上一条）。如果确实是存档但全部读不出来，可能是文件本身损坏了。可以试试游戏本体能否读取——如果游戏也读不了，这个存档可能已经无法恢复。

## 关于内容

**Q：某个道具显示成「道具 #1234」。**

工具认识的道具名有限。这个存档里的道具编号不在内置名单中。不影响存档本身的正确性，只是显示为编号。

**Q：「累计游玩 0 分钟」但我明明玩了很久。**

早期版本的存档格式不记录游玩时长，这属于正常情况。新版本存档才有这项数据。

**Q：导出报告里为什么写「原始存档未被修改」？**

这是工具的行为声明，提醒你导出内容是**读取结果**，不是存档的备份。如果你需要真正的存档备份，请直接复制游戏生成的原始存档文件。

## 关于使用

**Q：可以同时打开多个存档吗？**

一次只能打开一个文件。需要看另一个时，点击「换一个存档」。

**Q：界面打不开，浏览器一片空白。**

程序运行后会在命令行/终端里打印一个地址（例如 `http://127.0.0.1:51234/`），复制到浏览器打开。如果还是打不开，看程序窗口里有没有报错。

**Q：杀毒软件或系统提示「来自身份不明的开发者」。**

这个版本还没有做代码签名，所以系统会提示。点击「仍要打开」或「更多信息 → 仍要运行」即可，功能不受影响。

**Q：能用手机看吗？**

不能。工具在你的电脑上运行并在本机打开浏览器，不是网络服务，无法从手机访问。

**Q：多大的存档打开会慢？**

实测结果（同一台电脑，普通游戏存档通常远小于此）：

| 存档大小 | 大概需要 | 说明 |
|----------|----------|------|
| 2 MB | 不到 1 秒 | 无感 |
| 10 MB | 约 2~3 秒 | 正常范围 |
| 50 MB | 约 11 秒 | 会明显感到等待 |
| 100 MB | 约 25~35 秒 | **会长时间没反应，请耐心等待，不要重复点击** |

同时占用的内存大约是存档大小的 4 倍（100 MB 存档约占 400 MB）。

> 如果你的存档在 50 MB 以上，等待期间界面不会有任何变化——
> 这是当前版本的已知限制，我们正在优化。在优化完成前，
> **遇到大存档请只点一次打开，然后等待**。

**Q：打开大存档时界面没反应，是不是坏了？**

不是。工具正在解析，期间界面不会刷新，但程序仍在运行。
上面的表格给出了大致等待时间，在对应时间内完成都是正常的。
如果等待远超表中时间仍未出结果，那才可能是异常，请重新启动程序。
