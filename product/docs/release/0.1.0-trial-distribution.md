# 存档查看器 0.1.0 · 未签名试用分发说明

> 这是一份**试用**分发，不是正式发布。请先读完本文再决定是否使用。

---

## 一、这是什么

一个**只读**的本地存档查看工具：打开游戏存档文件，查看里面存了什么，
并能导出成 JSON 或可读报告。

它**不会修改你的存档**，也**不会联网**。

## 二、重要提醒：程序未做代码签名

Windows 无法确认这个程序是谁发布的，因此首次运行时会提示：

> Windows 已保护你的电脑 / Microsoft Defender SmartScreen 已阻止启动不受信任的应用

**处理方法：**

1. 点击「更多信息」
2. 点击「仍要运行」

不绕过就无法启动，这是预期行为，不是程序出错。

如果你对这个提示感到不安，**最稳妥的选择是不使用本工具**。
它是一个试用版本，没有做过公开分发应有的安全审查。

## 三、如何确认你拿到的文件没被篡改

因为没有代码签名，**请务必自行核对校验值**。

在 PowerShell 中执行：

```powershell
Get-FileHash .\save-inspector-0.1.0-Windows.zip -Algorithm SHA256
```

把输出的值与下表比对，**必须完全一致**：

| 文件 | SHA256 |
|------|--------|
| `save-inspector-0.1.0-Windows.exe` | `8a55a2f17a495ad59c4b94d9c151ef974469bda09effe5757c890a24488794b9` |
| `save-inspector-0.1.0-Windows.zip` | `ead890f0d8b53e39d80b2b05a84079112fa87003f128e47aa0d65700f5c14c11` |

**若不一致，请不要运行，删除该文件。**

> 校验值只能证明文件与发布时一致，**不能证明它安全**——
> 它无法替代代码签名。校验值的意义在于：如果你从多个渠道拿到不同的文件，
> 能立刻发现有人在中间动过手脚。

## 四、两种形式怎么选

| 文件 | 说明 |
|------|------|
| `save-inspector-0.1.0-Windows.zip` | **免安装**。解压后直接运行 `bin\save_inspector_ui.exe`，不用写系统任何位置。试用建议选这个 |
| `save-inspector-0.1.0-Windows.exe` | 安装到 `C:\Program Files (x86)\存档查看器\`，带开始菜单快捷方式，可从「设置 → 应用」正常卸载 |

试用场景建议用 **ZIP**：卸载只需删文件夹，不留痕迹、不改注册表。

## 五、怎么用

1. 解压 ZIP（或运行安装器）
2. 双击 `bin\save_inspector_ui.exe`
3. 程序会打印一个本机地址（形如 `http://127.0.0.1:51234/`），
   在浏览器打开它
4. 把存档文件拖进页面，或点击选择文件

**不会联网**：程序只在 `127.0.0.1` 上监听，出站连接为零。

## 六、出问题怎么办

| 现象 | 处理 |
|------|------|
| 杀毒软件报毒 | 先用上面的校验值确认文件未被篡改。**校验值一致**时可按误报处理（加白名单）；**校验值不一致**则删除，不要运行 |
| 系统提示未知开发者 | 见 §二，这是预期行为 |
| 打开某个存档失败 | 页面会说明失败原因（不是存档 / 加密 / 版本过新 / 损坏等），并给出建议 |
| 想彻底移除 | ZIP 形式：删掉解压出来的文件夹即可；安装形式：运行 `Uninstall.exe`，或在「设置 → 应用」中卸载 |

## 七、这次试用的已知限制

请在使用前了解，避免误判为故障：

| 限制 | 说明 |
|------|------|
| 只支持一种存档格式 | 不是通用的游戏存档查看器。读不了别的游戏的存档 |
| 不解密、不解压 | 加密或压缩过的存档读不了，会明确告知原因 |
| 只读 | **不能**写回、修档、修复存档。需要备份请直接复制原文件 |
| 大存档占内存 | 100 MB 存档打开后约占 400 MB 内存。内存紧张请先关掉程序 |
| 仅 Windows | 本次只提供 Windows 版 |
| 无自动更新 | 不会自动更新，也没有更新提醒 |

## 八、反馈

发现问题请附上：

- 校验值（§三）
- 你的 Windows 版本
- 程序窗口里的报错文字
- 如果是存档读取失败，请说明**存档多大**、以及页面显示的失败原因

请**不要**附上存档文件本身——本工具不需要你的存档内容就能定位大部分问题。
