## 4. 关键决策

| 决策 | 理由 | 被否决的备选 |
|------|------|--------------|
| 文件传输放到“工具栏/附加功能”分组 | 不与现有硬件报告主信息冲突 | 放到首页主内容区，会改变核心界面结构 |
| 显示“允许保存目录”而非完整绝对路径 | 降低泄露风险，提高可理解性 | 显示完整系统路径 |
| 失败时只有友好提示 | 不暴露内部错误，降低系统信息泄露 | 直接展示 HTTP 状态码或技术错误 |
| 下载前明确文件名 | 防止用户误下错误文件 | 自动下载 |
| 不支持目录浏览 | 范围太大，会引入目录权限风险 | 显示完整目录树 |

## 5. 风险与阻塞

- 前端默认哑接口，必须由后端提供上传/下载；
- 文件大小和允许目录需与后端契约完全一致；
- 需安全审查路径穿越风险。
