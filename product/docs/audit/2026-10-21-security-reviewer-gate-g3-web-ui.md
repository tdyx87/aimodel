# security-reviewer — G3 安全复核（本地 Web UI）

| 字段 | 内容 |
|------|------|
| 角色 / 时间 / 任务 | security-reviewer / 2026-10-21 / 复核 Web UI 这一新攻击面（本地 HTTP 服务可驱动模型执行命令） |
| 结论 | 无 Critical / High（可放行 G3）；有 2 项 Low 建议 |

## 1. 输入

- `docs/audit/2026-10-21-cpp-implementer-web-ui.md`、`2026-10-21-reviewer-gate-g2-web-ui.md`
- ADR-0005（安全取舍四条）；契约 §5.2 P1–P5、§15（Web UI 规定）

## 2. 检查项

| # | 风险面 | 结论 | 依据 |
|---|--------|------|------|
| S1 | **局域网暴露** | 无风险 | 绑定 `INADDR_LOOPBACK`（127.0.0.1），不是 `INADDR_ANY`；端口不会出现在外网接口上 |
| S2 | **本机其它进程**直接调用 API | 无风险 | 所有 `/api/*` 要求 32 字节系统熵令牌（`BCryptGenRandom` / `/dev/urandom`），比对失败 401；令牌只在启动时打印一次与出现在 URL 里 |
| S3 | **恶意网页**打过来（CSRF / 跨站） | 无风险 | 跨站请求**拿不到令牌**（同源策略读不到 URL 与响应）→ 401；页面也不用 cookie，状态不落在浏览器自动带上���东西上 |
| S4 | **DNS rebinding**（恶意站把域名指到 127.0.0.1） | 无风险 | 校验 `Host` 必须是 `127.0.0.1:<port>` 或 `localhost:<port>`，其它一律 401；即使令牌泄露，恶意站也无法伪造 Host |
| S5 | **XSS**（模型输出注入脚本） | 无风险 | 页面全部用 `textContent` 写入，**没有一处 `innerHTML`**；内容不作为 HTML 解析 |
| S6 | **路径穿越 / 任意文件读** | 无风险 | 服务端**不提供任何静态文件**（页面内嵌），没有「按路径读文件」的接口 |
| S7 | **命令执行**绕过批准 | 无风险 | Web 批准走 ui 层输入源（与终端同一套），`main_perm` 未改：`run_shell` 仍需 `CAGENT_ALLOW_SHELL=1`；策略拒绝时不询问用户（且回灌如实说明是策略拒绝） |
| S8 | **连接耗尽**（本机进程开无数连接） | 低风险 | 活跃连接上限 64，超出立刻 503 并断开；每连接一线程，64 线程的内存可忽略 |
| S9 | **SSE 客户端不读**导致代理卡死 | 低风险 | socket 设 `SO_SNDTIMEO=2s`；写失败即把该客户端标记 dead。理论上 32 个坏客户端最多拖住代理约 64 秒（串行发送），属**可用性**风险而非安全风险 |
| S10 | **内存**被请求体/队列撑爆 | 无风险 | 请求头 8 KB、请求体 64 KB、消息队列 32×8 KB、工具结果 1 MB（沿用 §2.1），全是定长；无 `malloc` 随输入增长 |
| S11 | **令牌泄露**（控制台历史/截图/日志） | 需知悉 | 令牌打在 stdout（用户需要它来打开浏览器）。缓解：只绑回环、令牌可随时重启更换。**建议**：不要把带令牌的 URL 贴到公开处 |
| S12 | **重放**（拿旧令牌请求） | 低风险 | 令牌在进程生命周期内固定；重启即换。已知的弱化项：没有「一次性/过期」语义 |
| S13 | 密钥是否可能经 Web 泄露 | 无风险 | Web 层拿不到 key（key 只在 core 的请求头里），事件里不含 key；`--probe` 打印「已设置/未设置」而非内容 |

## 3. 结论

未发现 Critical / High。Web UI 的攻击面被四道闸（回环监听、随机令牌、Host 校验、
run_shell 显式开启）加上「不提供静态文件、页面不用 innerHTML」共同覆盖。
放行 G3。

## 4. 建议（Low，不阻塞）

1. **令牌一次性化**：可在 `/api/*` 之外让令牌在首次成功使用后失效，或加短时效；
   当前形态下「本机已能读到你终端的人」本来就是威胁模型的一部分。
2. **SSE 发送并发化**：把 32 个客户端的写并行化，可把 S9 的最坏等待从约 64 秒降到约 2 秒。

## 5. 移交

`orchestrator` 记录 G4 口径；后续若开放局域网访问（不建议），必须先做
HTTPS + 真正的用户鉴权，不能沿用当前的「回环 + 令牌」模型。
