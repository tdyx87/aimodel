# 角色审计记录模板

> 生成路径：`product/docs/audit/<YYYY-MM-DD>-<role>-<task>.md`  
> 对应规范：`.role-system/agents.md` §6.6。所有字段必填。

---

## 1. 基础信息

| 字段 | 内容 |
|------|------|
| 角色 | <role-name> |
| 时间 | <YYYY-MM-DD HH:MM> |
| 任务 | <一句话任务> |
| 门禁 | 属于 G1 / G2 / G3 / G4 |

## 2. 输入 / 依赖

> 说明本次审计消费的上游产物。

| 输入 | 路径 / 来源 |
|------|-------------|
| 上游产物 | <文件或文档> |
| 依赖 | <版本/文件/前置审计> |

## 3. 证据锚点

> 让审计可回溯到具体文件、行或副本。

| 证据 | 位置 |
|------|------|
| 关键文件 | <文件路径> |
| 关键行 | <行号或片段> |
| 关键证据 | <摘录> |
| 产物引用 | <文件路径> |

## 4. 关键决策

> 做了什么选择 + 理由 + 被否决的备选。

| 决策 | 理由 | 被否决的备选 |
|------|------|--------------|
| <决策> | <理由> | <备选> |

## 5. 风险与阻塞

> 记录本次审计中发现的卡点、风险或需后续处理的事项。

- <风险/阻塞项>：<描述>
- <风险/阻塞项>：<描述>

## 6. 产出

| 产物 | 路径 |
|------|------|
| <产物类型> | <文件名或结果> |
| <产物类型> | <文件名或结果> |

## 7. 结论

| 项 | 内容 |
|------|------|
| 角色级裁决 | <✅ 通过 / ❌ 需改 / 完成并移交> |
| 风险 / 影响 | <Critical / High / Medium / Low> |
| 备注 | <局部结论或已知局限> |

## 8. 复核记录

> `orchestrator` 放行前至少抽检 1 份上游审计，复核后回写此字段。

- 复核人 | <orchestrator / 下游角色>
- 复核时间 | <YYYY-MM-DD HH:MM>
- 复核结论 | <通过 / 打回>
- 复核摘要 | <核对了什么、是否一致、是否打回>

## 9. 移交

| 项 | 内容 |
|------|------|
| 交给 | <下游角色> |
| 下游依据 | <产物/契约/门禁> |
| 开工前提 | <下游按哪些输入开工> |
