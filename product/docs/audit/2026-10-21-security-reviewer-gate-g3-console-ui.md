## 2. 检查项

| # | 风险面 | 结论 | 依据 |
|---|--------|------|------|
| S1 | `--probe` 是否打印密钥 | 无风险 | 只输出「已设置（不显示内容）」/「未设置」；`Authorization` 头只进请求不进 stdout |
| S2 | 错误文案是否泄露主机名/路径/凭据 | 无风险 | 只取**主机部分**（到第一个 `/` 或 `?` 为止），不含路径、查询串、用户名口令；`ca_http_status_text()` 明确「不含本机路径、不含凭据」 |
| S3 | 响应片段是否可能含服务端回显的凭据 | 低风险（可接受） | 最多 255 字节，仅 `--probe` 显式运行时打印，且不落盘、不进会话文件；正常对话路径不打印响应体 |
| S4 | 可视化层是否绕过工具批准 | 无风险 | 只改渲染，不改权限链路；批准仍走 `ca_ui_confirm` → `cfg.perm`，默认拒绝 |
| S5 | 盒面板是否泄露待批准内容的**位置信息** | 无风险 | 面板内容就是原本要展示给用户看的内容（路径/命令原文），P2/P5 要求展示，不构成新增泄露 |
| S6 | `ca_term_setup_console()` 是否影响重定向/管道 | 无风险 | 只改控制台代码页与 ANSI 开关；重定向时 `GetConsoleMode` 失败即不做任何事，写出的仍是 UTF-8 字节 |
| S7 | 新增代码是否引入**动态分配**或无界缓冲 | 无风险 | 面板与捕获缓冲均为定长栈缓冲（1024 / 256 字节），无 `malloc` |
| S8 | 是否引入新的网络出口 | 无风险 | `--probe` 复用同一 transport 与同一 `CAGENT_API_BASE`，不新增域名/端口逻辑 |

## 3. 结论

未发现 Critical / High 风险项。本轮改动集中在**呈现层与错误分类**，
不触碰授权路径、不新增数据出口、不改变密钥处理方式。放行 G3。
