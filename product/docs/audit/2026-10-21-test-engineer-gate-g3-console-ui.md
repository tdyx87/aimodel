## 5. 未覆盖（如实登记）

1. **真实 Windows 控制台的人工观感**（颜色、边框对齐、中文渲染）只能人工确认：
   CI 的 runner 没有交互式控制台，本仓库也**不提供** Windows ConPTY 驱动的自动化。
   已用「TTY 分支的单测 + 文档规定」兜底，但不能替代真人看一眼。
2. **Ctrl-C 路径**未自动化：需要向子进程发 `CTRL_C_EVENT`（Windows）或 `SIGINT`（POSIX），
   当前测试框架没有这个能力。该路径靠代码审查（reviewer R7）保证。
3. **`--probe` 的退出码**未进单测（它是 `main` 里的分支，单测不覆盖 `main`）；
   已用人工四次运行核对（正常/缺 key/无网络/错模型）。
