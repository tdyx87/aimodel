# design：文件传输 UI

> 产出者：ui-designer
> 审计：product/docs/audit/2026-10-12-ui-designer-file-transfer.md

---

## 1. 组件位置

文件传输区域放置在 `system_info_ui` 的“工具栏/附加功能”分组内，名称为：

```text
文件传输
```

---

## 2. 页面结构

```text
文件传输
├── 标题：文件传输
├── 上传区域
│   ├── 拖放区
│   ├── 文件选择
│   ├── 当前文件列表
│   └── 状态
├── 保存位置
│   └── 显示“允许保存目录：XXXX”
└── 下载区域
    ├── 文件列表
    └── 下载按钮
```

---

## 3. 状态设计

| 状态 | 显示内容 |
|------|----------|
| 空态 | 页面可见，提示“选择文件上传” |
| 选择文件 | 显示当前选择文件 |
| 上传中 | 显示进度、文件名、完成时间 |
| 成功 | 显示“上传成功”和保存位置 |
| 失败 | 显示错误原因和重试 |
| 路径不合法 | 提示用户调整路径 |
| 无权限 | 提示选择可写入目录 |
| 超出限制 | 提示文件过大或文件名非法 |

---

## 4. 交互规则

1. 只能选择本地文件；
2. 不展示内部完整路径；
3. 上传失败时显示“失败原因”；
4. 路径校验失败时停留用户并提示；
5. 无权限时提示用户选择另一个目录；
6. 成功后展示保存位置；
7. 下载前必须确认文件来源；
8. 每次状态变化不丢失上次选择的文件名。

---

## 5. 错误文案

### 路径不合法

```text
路径不合法，请选择“允许保存目录”内的文件名。
```

### 无权限

```text
没有权限访问该目录，请选择一个可写入的目录。
```

### 超大

```text
文件过大，请选择小于 10 MB 的文件。
```

### 文件写入失败

```text
保存文件失败，请检查目录是否可写入。
```

---

## 6. 安全提示

- 禁止展示绝对路径；
- 禁止展示内部文件结构；
- 必须由后端判定是否允许；
- 前端错误只能提示用户，不能提示后端细节；
- 下载前必须确认文件来源；
- 路径穿越错误必须由服务端拦截。

---

## 7. 验收

- 上传成功后可见正确成功提示；
- 路径穿越失败时提示友好；
- 无权限时提示；
- 文件大小超限时提示；
- 下载后文件内容一致；
- 页面不破坏原 `system_info_ui`。
