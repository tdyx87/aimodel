## 2. 状态矩阵

| 界面状态 | 触发条件 | 表现 |
|---------|---------|------|
| **首屏空态** | 未选择文件 | 居中拖放区 + 「选择或拖放一个存档文件开始」+ 选择按钮 |
| **解析中** | 读取中 | 骨架屏（3 行卡片占位）；NFR-2 下不得长时间无响应 |
| **列表正常** | 解析成功且有槽位 | 如上图 |
| **空存档** | `slot_count == 0` | 空状态「这个存档还没有任何槽位」+「用游戏本体创建并保存一次」 |
| **整体损坏** | `magic` 不符 / 版本过新 / 截断 | 切换到 `diagnosis.md` 的诊断视图，**不显示列表** |
| **部分损坏** | 槽位级错误 | 正常显示列表，异常槽位用 `degraded`/`corrupt` 态 |

> `整体损坏` 与 `部分损坏` 必须**视觉区分**：前者是「整个流程走不通」，后者是「能看，但有坏的」。

---

## 3. 交互

| 操作 | 行为 |
|------|------|
| 点击「打开存档」/ 拖放文件 | 读取并解析；进入解析中态 |
| 点击槽位卡片 | 进入 `slot-detail.md` |
| 悬停卡片 | 出现「查看」按钮；卡片提亮 |

拖放区必须同时支持点击选择与键盘（设计系统 §6）。

---

## 4. 数据来源

| 元素 | 契约字段 |
|------|---------|
| 文件名 | 路径末段（**不显示完整路径**，契约 §5） |
| 槽位数 | `save.slots.length` |
| 最后保存 | `slot.last_played_utc` 取最大值 |
| 升级提示 | `diagnostics` 中 `severity=info` 的条目 |
| 卡片健康态 | `slot.healthy` |

---

## 5. 不得出现

- 用户的完整本机路径（契约 §5 硬约束）
- 错误码、文件偏移量、堆栈（PRD US-5 硬约束）
- 任何写回/修复存档的按钮（PRD §4 范围外）
