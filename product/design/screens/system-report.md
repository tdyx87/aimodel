# 界面稿：硬件报告主页（system-report）

> `ui-designer` 产出，交付 `frontend-implementer`。这是产品**唯一主页面**（单屏仪表盘）。

## 1. 线框

```text

│ ┌─ 处理器 ──────────────┐  ┌─ 显卡 ─────────────────────────┐ │
│ │ Intel i5-10500 @3.1GHz│  │ AMD Radeon R7 430     2 GB 显存 │ │

```

- 布局：桌面双列网格（≥768px 两列，窄屏单列）；卡片顺序按用户关心度：处理器/显卡/内存/磁盘/打印机。
- 内存、磁盘用量用进度条（>85% 变警示色并显示"空间紧张"提示）。

## 2. 状态设计（逐块）

| 块 | 正常 | 空态 | 错误态 |
|----|------|------|--------|
| 处理器/内存 | 数据 + 进度条 | 不适用（必有值） | "检测失败，点击重试"（块级重试） |
| 显卡 | 型号 + 显存（0 显存显示"共享内存"） | "未检测到显卡" | 同上 |
| 磁盘 | 每盘一行 + 进度条 | "未检测到磁盘" | 同上 |
| 打印机 | 列表 + 状态点 + 默认标记 | "未检测到打印机" | 同上 |

- **全局加载态**：首屏全部卡片骨架屏，顶栏播报"正在检测你的电脑配置…"。
- **全局错误态**：仅当整体请求失败（服务断开），页面居中：😢 "无法获取硬件信息" + "请确认 aimodel 正在运行" + 重试按钮。
- **刷新**：顶栏按钮触发，保留旧数据 + 局部骨架（不整页闪白）。

## 3. 交互

| 动作 | 行为 |
|------|------|
| 打开页面 | 自动加载一次报告 |
| 点刷新 | 重新拉取，顶栏 `aria-live="polite"` 播报"已更新 · 时间" |
| 请求 >3s | 顶栏显示"仍在检测…"，不打断 |
| 点块级重试 | 仅重试该块数据（同接口，整体刷新简化实现由 architect 定） |

## 4. 交付验收（frontend-implementer 完成标准）

1. 与本线框一致（卡片顺序、四态齐备、隐私徽标常驻）。
2. 样式全部走 `design/design-system.md` 的 CSS 变量与类，无内联硬编码颜色。
3. 断网/服务断开不白屏（全局错误态 + 重试）。
4. 键盘可达 + 语义化标签 + 进度条 ARIA。
